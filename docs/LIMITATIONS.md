# Limits and named failures

This is not a privacy guarantee. Construction is source-only and runtime-unverified. No measured result exists.

Expected misses: names in ordinary prose; identifiers split mid-token; novel unprefixed tokens below the entropy threshold;
tool output outside details treated as assistant text; negation, relation swaps and paraphrase fabrications;
convincing forged speaker headings. English sentence splitting is conservative and can over-refuse abbreviations or lists.
Lexical support does not establish truth or semantic entailment. Manual review is mandatory.

Raw imports, deny-list values, drafts and placeholder maps live in memory. Approval hashes live in IndexedDB;
storage denial blocks approval and clearing storage loses history. No identity authentication is implied by imported roles.
R1 has a frozen limited rule set, including a PEM header-only rule. R0 and R1 are evaluator-only controls and never product outputs.
Each control uses its own redaction policy; only R2 uses the full detector rescan. All share the serializer and grounding checks.
The oracle matches planted values separately from detector rules; partial-secret windows can count a shared fragment as a leak.
Small cells, repeated seeds and sessions from the same template do not justify broad population claims or confidence intervals.
